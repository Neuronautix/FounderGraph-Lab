## Purpose

- This file is part of a synthetic but realistic Metadatapp knowledge base for a mock knowledge-graph experiment.
- It is point-ended by design: short claims, explicit entities, explicit relations, and open questions are easier to extract into a graph.
- Client and partner situations are fictionalized unless described as standards, technologies, or general market concepts.

## Key points

- Phase 1 delivers core entities, CSV import, validation report, JSON-LD export, and ARRIVE draft.
- Phase 2 adds connector prototypes, ontology suggestions, RO-Crate packaging, audit logs, and pilot dashboards.
- Phase 3 adds commercial pilot onboarding, reusable templates, and support workflows.
- Phase 4 adds SSO, private deployment, connector SDK, and knowledge graph query interface.
- Automated VCG modeling should remain a later-stage feature after readiness validation is credible.
