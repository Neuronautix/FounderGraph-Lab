## Key points

- Open with a broken dataset example where numbers remain but context is missing.
- Explain why retrospective FAIRification is expensive and incomplete.
- Define FAIR-by-design as capturing metadata when context is known.
- Use HCM as the example because longitudinal data need protocol and facility context.
- Explain how validation and ontologies improve reliability.
- End with a boundary: FAIR metadata enables reuse but does not remove scientific judgment.
